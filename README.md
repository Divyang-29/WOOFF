# Wooff Kids - 100% Prebiotic & Fluoride-Free Oral Care

Wooff Kids is a dentist-created, premium oral care brand designed around a simple belief: brushing shouldn't be a morning battle — it should be a fun, delicious daily ritual kids look forward to and parents feel 100% confident about.

## 🚀 Tech Stack

- **Frontend**: React (Vite), React Router v6, FontAwesome 6, Custom CSS
- **Backend**: Node.js, Express.js, PostgreSQL, Cloudinary
- **Architecture**: REST API, Full-Stack E-Commerce Architecture

## 📁 Repository Structure

```
Wooff/
├── Backend/        # Node.js & Express API Backend
└── frontend/       # React (Vite) Frontend Application
```

## 🛠️ Getting Started

### 1. Backend Setup
```bash
cd Backend
npm install
npm run dev
```

### 2. Frontend Setup
```bash
cd frontend
npm install
npm run dev
```
